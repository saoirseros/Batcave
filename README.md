# 🦇 Batcave: Superhero-Themed Animated Landing Page

This project is a **fully responsive**, **superhero-themed landing page** and functional **web application** demonstrating strong command of **vanilla front-end technologies**.  
It highlights **clean design**, **smooth CSS animations**, and **dynamic JavaScript functionality** for enhanced user engagement.


## Key Features

- **Custom Dynamic Carousel:**  
  Built a custom, interactive image carousel using pure JavaScript to manage state, handle events, and manipulate the DOM.  

- **Aesthetic & Responsive Design:**  
  Applied modern CSS3 techniques and keyframe animations to create a visually rich interface that adapts seamlessly across devices.  

- **Zero Framework Dependency:**  
  Developed entirely with **core web technologies (HTML, CSS, JavaScript)** — no external frameworks or libraries used.


## Technology Stack

| Layer | Technologies Used |
|-------|--------------------|
| **Structure** | HTML5 |
| **Styling & Animation** | CSS3 (custom animations, keyframes, transitions) |
| **Interactivity / Logic** | JavaScript (Vanilla ES6+) |


## Getting Started

This project is **fully client-side** and requires **no local server setup**.

Clone the Repository and Open index.html with your browser

git clone https://github.com/saoirseros/Batcave-Animated-Landing-Page

cd Batcave-Animated-Landing-Page
